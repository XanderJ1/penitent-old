# ViV-inspired PENITENT presentation

Reference inspected at desktop (1440px) and mobile (375px): https://vivmgmt.com/ on 12 October 2026.

Adapted sparse navigation, oversized sans-serif identity, staggered portrait image columns, generous white space, and editorial collection links. PENITENT uses its own identity, original copy, and illustrative Unsplash clothing photographs; no ViV photography or logo is included in the storefront.

The home screen links to the existing categories and collection. Product listings, variants, persistent bags, checkout previews, wishlists, and protected admin remain connected to the existing .NET/PostgreSQL API. Entrance animations honour reduced-motion preferences. Mobile menus and links remain keyboard accessible.
